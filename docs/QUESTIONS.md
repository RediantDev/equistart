# Открытые вопросы к заказчику

Формат: вопрос · почему важно · что сделано пока · к какому этапу нужен ответ.
Решённые вопросы переносятся в журнал решений ТЗ (раздел 19).

## Открыто

1. **Шаблоны результатов по дисциплинам** (`docs/DISCIPLINES.md`). Пока результаты вводятся вручную, поля по умолчанию — по таблице. Заказчик рассылает опрос судьям (документ «Опрос для судей EquiStart»); по ответам и регламентам — утвердить шаблоны и правила ранжирования, затем делать автоподсчёт.
2. **Реквизиты ИП** (OPERATOR_* в настройках) — заказчик пришлёт позже.
3. **Сроки хранения персональных данных** — исполнитель предложил варианты (см. ниже), ждём решения заказчика.
4. **Оплата: переплата, аванс, правила возврата** — заказчик пока не готов решать. Сейчас: переплату касса не принимает, решения о списании и возврате при отмене — вручную.

### Предложение по срокам хранения (п. 3)

| Данные | Предлагаемый срок |
|---|---|
| Аккаунт (ФИО, телефон) | пока аккаунт существует; после удаления — 30 дней, затем удаление |
| Профиль спортсмена, лошади, документы лошади | пока ими управляет представитель; после удаления — 30 дней |
| Заявки, решения, начисления, отметки об оплате | 5 лет после турнира (споры, отчётность организатора), затем обезличивание |
| Опубликованные протоколы и результаты (ФИО, год рождения) | бессрочно — спортивный архив; по отзыву согласия на распространение — ФИО скрывается |
| История действий (журнал) | 3 года |
| Коды подтверждения телефона | 1 сутки |

## Напомнить заказчику перед запуском

- **Уведомление в Роскомнадзор** от ИП (pd.rkn.gov.ru) — заказчик подаёт в последнюю очередь, но до сбора данных реальных людей. Пункт в чек-листе `docs/DEPLOY.md`.
