# Дисциплины и виды программ — на подтверждение

Сейчас в сервисе — все дисциплины ФКСР. Вид программы подставляет поля результата по умолчанию; судья может их изменить. Автоматический подсчёт мест не делается, пока эта таблица не утверждена.

Что нужно от заказчика: проверить список видов программ и поля результата; дописать недостающие; для автоматического подсчёта — правила ранжирования (например, «меньше штрафных очков, при равенстве — меньше время»), ограничения числа стартов лошади в день и минимальный отдых между стартами.
