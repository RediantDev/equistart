# Посмотреть EquiStart на своём компьютере

Сайт запускается только у вас: адрес http://localhost:8000, из интернета его не видно. Уже есть тестовый турнир, участники, заявки и судьи.

## 1. Установить Docker Desktop (один раз)
- Скачайте с https://www.docker.com/products/docker-desktop/ (Windows или Mac) и установите.
- Windows: если установщик попросит включить WSL 2 — согласитесь и перезагрузите компьютер.
- Запустите Docker Desktop и дождитесь зелёной надписи «Engine running» внизу окна.

## 2. Распаковать проект
Распакуйте архив `equistart.zip`, например в папку «Документы» → получится папка `equistart`.

## 3. Запустить
- **Windows:** откройте папку `equistart` в Проводнике, щёлкните по адресной строке, введите `powershell` и нажмите Enter.
- **Mac:** откройте «Терминал», введите `cd ` (с пробелом), перетащите папку `equistart` в окно и нажмите Enter.

Введите команду и нажмите Enter:

```
docker compose -f docker-compose.local.yml up --build
```

Первый запуск — 5–10 минут (скачивается всё нужное). Когда появится строка **«Сайт готов: откройте http://localhost:8000»** — откройте этот адрес в браузере. Окно терминала не закрывайте, пока смотрите сайт.

## Остановить и запустить снова
- Остановить: в окне терминала нажмите **Ctrl+C**.
- Запустить снова — та же команда; второй раз стартует за несколько секунд, введённые данные сохраняются.
- Начать с чистыми тестовыми данными: `docker compose -f docker-compose.local.yml down -v`, затем снова команду запуска.

## Если что-то не так
- **«Forbidden» или «failed to resolve reference» при скачивании** — Docker Hub недоступен из вашей сети. В Docker Desktop: Settings → Docker Engine, добавьте строку `"registry-mirrors": ["https://dockerhub.timeweb.cloud"],` после первой `{`, нажмите «Apply & restart» и повторите команду.
- **«port is already allocated»** — занят порт 8000: закройте другую программу, которая его использует, или перезагрузите компьютер.
- **«docker: command not found» / «cannot connect to the Docker daemon»** — не запущен Docker Desktop.
