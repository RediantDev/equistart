# Симулятор пользователей EquiStart

Прогоняет турниры «как живые люди»: только через видимые ссылки и формы сайта, с персонами разного уровня
цифровизации (уверенные 45 %, средние 35 %, новички 20 % — типичные ошибки ввода, пропуски согласий, повторные нажатия).

| Сценарий | Что проверяет |
| --- | --- |
| `scenario1.py` | Конкур, 4 дня, 20 маршрутов, ~400 пар; денники и услуги, гонка за последний денник |
| `scenario2.py` | Конкур, 1 день, 5 маршрутов, 30 пар (в одном маршруте 2 пары) |
| `scenario3.py` | Выездка, всероссийские, 4 дня, 10 езд (детская, КЮР), бригада 5 судей + подсчёт |
| `scenario4.py` | Выездка, 1 день, 3 судьи + подсчёт |
| `scenario5.py` | Сложные случаи: 21 проверка (возврат модератором, двойная отправка, одновременные решения судей, правка опубликованного турнира, поздняя заявка, объединение зачётов, снятие после публикации, повтор отправки у поля, исправление результата, возврат листа выездки) |

Запуск на локальном стенде (сервер на 127.0.0.1:8000, база очищается): `./run_all.sh`.
Скриншоты и метрики вёрстки 1440/390/360: `python3 shots.py` (нужен Chrome и playwright).
Журналы: `requests.jsonl` (время и размер каждого ответа), `friction.jsonl` (где спотыкаются персоны).

Пути `/home/claude/...` и `env.sh` — из тестовой среды; поправьте под свою машину.
